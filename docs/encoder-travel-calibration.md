## 后续卷线的强制约束

- 物理行程区间为 0–34891 ticks；回卷不得越过零点，放线不得越过上端点。
- 应在端点之前停机，留出根据速度和停机惯性实测的余量；本次尚未标定余量。
- 必须在固件层覆盖自动 Winding、手动 MF/MR 以及等待训练确认的执行路径，不能只靠上位机限制。
- 启动时物理位置未知则禁止电机，须在原机械零点确认归零。训练 Start 的相对清零不能移动物理限位基准。
- 编码器无反馈、计数方向异常、超时均须停机；到端点不能使用试转并自动反向的旧逻辑。
