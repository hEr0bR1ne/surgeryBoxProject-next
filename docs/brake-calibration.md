# 刹车角度标定

2026-09-09 已整合用户导出的 hardware_tests/servo_calibration.json。
板型 WEMOS D1 R1，舵机信号 D2 / GPIO16。

| 状态 | 指令角度 | 命令 |
| --- | ---: | --- |
| 释放（上电默认） | 0° | BR |
| 弱阻尼 | 55° | BW |
| 锁紧 | 125° | BL |

训练事件使用同一组角度。Stop 仍锁紧，现为 125°。这些是指令角度，不是测得的角度或刹车力。
BRAKE? 查询最后指令角度；BRAKE:ANGLE:5 微调允许 0–125° 的整数，单次最大 5°，训练或回卷期间拒绝。配套 tools/calibrate_brake.py 已同步范围。
微调仅保存在 RAM，重启主固件回到 0°。需烧录新版主固件才在板子生效；独立编码器测试不控制舵机。
