# 第三代全功能测试端

双击`tools/StartHardwareTest.cmd`。当前COM4已烧录3.1.6 / protocol=8。把线放到想停的位置后，点「设为回卷零点」。新零点在主板重启前有效。
其他电脑Python3.10+：`pip install -r host_sdk/requirements-gui.txt`。

上电位置由MCU自动记为零点，测试端连接只查询，不会重新归零或移动机构。无需登记收回端、拉出端或测距离。
在电机空闲且编码器跟踪有效时，可以手动设置回卷零点。显示归零只影响训练用相对计数。

- 编码器：相对计数/圈数、单圈角度、有效性、错误计数、显示归零、10Hz上报。
- 舵机支持 180° 释放、90° 弱阻尼、30° 锁紧和停止脉冲。微调范围 30～180°，单次最多 5°，缓动速度 75°/秒。
- 灯：D3开关及引脚回读。
- 电机：确认供电与机构可动后点自动回卷，无拉出上限、无提前停止死区；返回当前回卷零点后释放摩擦轮1秒。
- 仅释放1秒、正常提前结束并释放、急停、全部关闭、日志导出。

错误方向、失联、编码器故障、500ms无进展仍会停机，连续回卷上限120秒。
数据过期或回卷零点失效会禁用回卷。零点因编码器失去连续性而失效时，须重新上电，不能通过显示归零或重连掩盖。
窗口失焦/关闭以及空格/Esc发送SAFE；故障或急停不自动反向。电机动作均由用户按钮触发。
每次固件重启会自动选取新的上电零点，电脑端重连不改变零点。

日志在`test_logs/hardware_*.txt`，JSON导出包含身份、状态与动作结果。只允许一个程序占用COM4。
主接口与物理惯性限制见`docs/v3-hardware-api.md`。
