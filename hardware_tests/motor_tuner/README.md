# A4950输入组合点动工具

接线恢复为D7/GPIO13→AIN1、D8/GPIO0→AIN2。双击StartMotorTuner.cmd，选择COM4连接。需配套支持 `matrix=1` 的新版保护主固件；启动不会自动连接或运行。

每个输入支持LOW、PWM、HIGH，组合编号为AIN1状态×3＋AIN2状态，其中LOW=0、PWM=1、HIGH=2。

|编号|AIN1|AIN2|
|---|---|---|
|0|LOW|LOW|
|1|LOW|PWM|
|2|LOW|HIGH|
|3|PWM|LOW|
|4|PWM|PWM|
|5|PWM|HIGH|
|6|HIGH|LOW|
|7|HIGH|PWM|
|8|HIGH|HIGH|

建议按界面顺序先测试1、3、5、7，再测其余组合；每项手动点击，不自动遍历。默认PWM512/1023、200ms；普通组合可选100～2000ms。2和6为全驱动，PWM滑块无效，固件和工具均限制最多200ms。PWM/PWM使用相同占空比及500Hz，但没有测量实际相位，不能把它当作理想同步波形证明。0和8也仅作定时输入组合实验，结束统一回到两脚LOW。

上电后原点无效：在编码器已供电时回原机械零点，勾选登记，再手拉至14000～20000计数并停稳。所有外设最终由外部24V供电，断电期间移动不能被记录。行程边界1745～33146、提前停止点1945不变；任一方向移动150计数提前停止，固件独立执行时限。组合测试不预设回卷/脱离方向，也不会自动建立回卷方向。停车惯性尚未验证。

每次观察后选择“明显收线”“离合器已脱离”等并保存到最近一次，再导出JSON。导出包含组合编号、两个输入模式、PWM、时长、位移、停止原因与两脚瞬时读回。PWM瞬时读回不代表占空比、电机转向或模块端电压。停止按钮发MS，关闭窗口尝试停止；断线后固件仍按时限结束。

协议：先MOTOR:PWM:512取得回执，再MOTOR:MATRIX:<0..8>:<100..2000>。TRAVEL状态包含matrix=1、combo和duration_ms；matrix_complete仅表示组合测试结束，不代表电机动作符合预期。禁止把0/1当作正反转编号。旧JOG接口保留，但本工具只使用MATRIX。
