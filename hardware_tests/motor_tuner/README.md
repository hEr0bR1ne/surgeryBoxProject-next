# 电机正反向点动工具

双击 `StartMotorTuner.cmd`，依赖 PySide6，启动器优先使用本机 surgeryBox 环境。

**2026-09-10已烧录新版根目录保护主程序并核对串口停止状态，尚未实测点动。** 换板或重刷后仍需核实固件。本工具会拒绝常转固件和缺少 `control=dir_pwm_v1` 的旧版主程序。软件连接不自动启动、不自动登记零点。

## 使用步骤

1. 烧录前断开整套24V、保留USB并关闭其他串口工具。刷入根目录主程序后，先确认启动电机停止，再恢复外设供电。
2. 选择COM4连接。外设（含编码器）均由外部24V供电。若零点无效，先在编码器供电时回到原机械零点，再勾选并登记；不可在中段任意归零。24V断电期间移动过，也必须重新确认原零点。
3. 手拉到14000～20000计数中段并停稳。保留这一区间用于首次动力点动，尚未开放全行程手动运行。
4. 选择正转F（回卷线盘）或反转R（脱离离合器，不是放线），设置驱动占空比和时间，点击“点动一次”。默认512/1023约50%、500ms；范围300～700、100～2000ms。改变参数不会自动运行。
5. 固件独立执行所选时长，GUI另发MS作为辅助停止。正转移动150计数提前停止，计数反向超过8则停止；反转离合器预期不带动编码器，任一方向移动8计数即停止。反转零位移不再报反馈不足，也不能据此确认回卷方向。
6. 记录机械观察，点击保存观察并导出JSON。窗口关闭会尝试发送MS；断线后仍由固件时限停止，USB断开并不是电机断电。

保护边界1745～33146、暂定提前停止点1945保持不变。动力惯性和离合器实际行为仍待验证；本窗口不发送完整Winding，不自动换向。反转需等本次运行停止后再选择，不能运行中切换。

## 电气控制与协议

D7/GPIO13→AIN1方向，D8/GPIO0→AIN2固定500Hz PWM。F方向D7低，D8高电平占空比等于设定值；R方向D7高，D8高电平占空比为1023减设定值，让滑块增加时两个方向的驱动比例都增加。停止时两个输入均低。

依据[A4950官方真值表（第4页）](https://www.allegromicro.com/-/media/files/datasheets/a4950-datasheet.pdf)：11为制动、10/01为两种驱动方向，因此反转需要补偿PWM高低有效区间。模块实际电路与停止惯性仍需实测；这里的正反转名称按用户的机械定义。

工具先发 `MOTOR:PWM:512` 并等待同值回执，再发 `MOTOR:JOG:F:500` 或 `MOTOR:JOG:R:500`。固件严格限制时长100～2000ms；MS停止，TRAVEL?查询。状态包含 `control=dir_pwm_v1`。旧PROBE命令仍保留2秒上限，但电气方向改为当前定义，旧工具应升级。

停止原因：probe_complete=正转获得双相回卷反馈；probe_insufficient_feedback=正转位移/反馈不足；clutch_jog_complete=反转点动已结束（不代表离合器实际动作已证实）；clutch_unexpected_movement=反转带动了编码器；wrong_direction=回卷计数方向异常；travel_stop=行程保护；stopped=MS等显式停止。
