# 电机手动测试窗口

双击 StartMotorTuner.cmd。使用当前已烧录的2秒保护版主程序，不需要重新烧录。依赖 PySide6，启动器优先使用本机 surgeryBox 环境。

1. 接通整套24V（编码器、电机、舵机、灯），主板USB连接，关闭其他串口工具，选择COM4连接。
2. 查看零点状态。若已确认，保留现有坐标；若需归零，先手动回原机械零点，再勾选确认并点击登记。不要在中段任意归零。USB重启或24V断电期间移动过，都需要重新确认原机械零点。
3. 手拉至14000–20000计数中段、停稳。运行按钮在未归零、位置超界、通信失效或运行期间禁用。
4. 选F或R、PWM和时间，点击运行一次。F/R仅表示电气方向，不预设哪边收线。默认PWM512约50%，可调300–700（约29%–68%）；这是输出占空比，不是测得的力。
5. 固件最多运行2秒，移动150计数会提前停；100–2000ms中较短的时长由窗口定时发MS，受到USB/系统调度延迟影响。界面停止按钮发送MS，不是硬件急停开关。不要指望断开USB立即断电；固件仍有2秒上限。
6. 观察轴、卷线轮及线的松紧；选择现场观察并保存到最近一次。导出motor_test_results.json发给我继续整合。

停止原因：probe_complete=获得足够位移；no_encoder_progress=超时无有效位移；probe_insufficient_feedback=位移或双相信号不足；travel_stop=行程保护；home_required=需确认原零点；probe_requires_14000_to_20000=不在测试中段。

窗口不发送完整Winding命令，不提供持续无限转动。保留控制边界1745–33146、预留停点1945及已有固件保护。当前尚未确认真实收线方向及停机惯性。连接主板可能因USB驱动引起复位；复位后零点无效，必须读回重新确认。
