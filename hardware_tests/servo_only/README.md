# 舵机单模块测试

独立 PlatformIO 工程，不编译主训练固件。替换板型号尚待确认，当前配置暂沿用 WEMOS D1 R1；信号输出为 GPIO16，对应 R1 的 D2。

先只通过 USB 给新板供电，外部 24V 与舵机电源断开，确认串口及无异常发热后再上传。核实舵机型号、额定电压、独立供电和共地，才接入舵机。此前发生发烫的供电线路未核实前不要接到新板。

启动不发送舵机脉冲，WiFi 关闭，不控制其他外设。首次 ENABLE 会命令到90°，不代表机械上的安全释放位置，应在机械行程已检查后执行。OFF 只停止信号，不能切断舵机电源。软件角度范围并不保证机械安全。

指令（115200 波特率、换行结尾）：

- `HELLO_PC`：回复 `ACK: SERVO_ONLY`，区分主训练固件。
- `SERVO?`：查询使能与最后设置角度，非实际角度测量。
- `SERVO:ENABLE`：开始输出90°；已启用时不重新定位。
- `SERVO:ANGLE:85`：使能后单步调整；60–150°，每次最多5°。
- `SERVO:OFF`：停止脉冲；不切断电源，不保证机械保持。

编译：`pio run -d hardware_tests/servo_only -e d1_servo_only`。
上传端口必须重新识别，不假定替换板仍为 COM4。
