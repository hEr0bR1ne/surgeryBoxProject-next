# 舵机手动角度调试工具

用途：手动选择角度、观察刹车阻力，记录释放/弱阻尼/锁定角度，然后将记录交回整合主程序。

## 第一步：手动烧录配套固件

当前自动往返程序不能接受角度控制，必须先换成此固件。接线保持 D1 R1 的 D2（GPIO16）为舵机信号；舵机由符合额定电压的外部降压电源供电，与开发板 GND 共地。烧录时先断开舵机外部电源，开发板通过 USB 供电。

Arduino IDE：打开 `ServoTuner/ServoTuner.ino`，选择 WEMOS D1 R1 和实际串口（当前 COM4），上传。

PlatformIO：打开本文件所在的 `servo_tuner` 文件夹，选择 `d1_servo_tuner` 环境上传。也可在这个目录运行：

```powershell
pio run -e d1_servo_tuner -t upload --upload-port COM4
```

这个固件上电不输出舵机脉冲，不会自动往返。不要与 `servo_manual` 自动往返固件或 `servo_only` 旧调试固件混用。工具只接受配套 `TUNER:1` 握手。

## 第二步：打开窗口

关闭 Arduino/PlatformIO 串口监视器，以免占用 COM4。双击 `StartTuner.cmd`。

启动器优先使用本机 `%USERPROFILE%\miniconda3\envs\surgeryBox\python.exe`（已验证带 PySide6），无需 pyserial。其他电脑先安装 `requirements.txt`，再运行 `python servo_tuner.py`。

选择 COM4，点击连接。连接仅查询状态，不启用动作。待连接成功，恢复已核实的舵机电源，并根据机械行程选择角度。

## 调试操作

1. 输入 0–180°，或拖动滑块。此时只选值，不会转动。
2. 点击“发送所选角度 / 启用输出”。固件每20ms改变1°，逐渐移向目标；输出会持续保持。
3. ±1° / ±5° / ±10°按钮会立即发送，以板子最近报告的目标角度为基准。
4. “输出角度”为板子当前已写入的控制角度，“目标角度”为这次指令终点。这不是实际轴位置、力或扭矩测量；普通三线舵机没有返回实际位置。
5. 点击“停止控制脉冲”结束输出。停止脉冲不切断舵机电源，也不保证机械释放或保持。
6. 找到合适角度、等待输出到达目标后，点击“记录为释放／弱阻尼／锁定”。角度变大不一定代表更紧，以实物安装为准。
7. 导出 JSON，发回记录文件，或直接告知三个角度。工具不会自动修改主训练程序。

软件支持0–180°不代表刹车机构允许整个范围。首次接管会先输出最后记录的指令角度（复位默认90°），随后渐变到新目标；未供电期间实际轴位置可能不同。扩大角度前应确认机械行程。

## 断线行为

关闭窗口或断开连接会尝试发送 OFF。固件3秒未收到有效指令/心跳会停止脉冲，防止程序退出后持续输出；断电或复位不会保存使能状态，也不会自动继续动作。停止脉冲仍不等于切断电源。

## 文件与验证

- `servo_tuner.py`：图形界面，PySide6 + QtSerialPort。
- `ServoTuner/ServoTuner.ino`：Arduino完整固件。
- `platformio.ini`、`src/main.cpp`：PlatformIO入口，共用上述固件。
- `preview.png`：无设备状态的窗口预览。
- `test_tuner.py`：无设备界面逻辑测试。

配套固件编译通过；7项界面逻辑测试通过，并检查了窗口渲染。此工具尚未替用户刷机，也未使用此固件完成实物角度标定。原先的独立自动往返程序已由用户确认能驱动舵机。

导出的 JSON 包含 `angles_deg.release`、`angles_deg.weak`、`angles_deg.lock`（可部分记录）、板型和引脚信息。记录保存在用户选择的位置，不上传任何数据。
